# СЛОВОБОЙ — Последний словарь

Браузерная typing-roguelite игра в пиксельном стиле. В центре стоит последний Словарь. К нему идут немые — существа со словами над головой. Введи слово, чтобы уничтожить врага, продержись 30 волн и победи Последнего Цензора.

## Запуск

Игра не требует сборки и зависимостей.

1. Открой `index.html` в современном браузере (Chrome, Edge, Firefox, Safari).
2. Или запусти локальный сервер из папки игры:

```bash
python -m http.server 8123
```

и открой `http://127.0.0.1:8123/`.

Локальный сервер рекомендуется: так стабильнее загружаются шрифты и `localStorage`.

## Управление

| Клавиша | Действие |
|---|---|
| Буквы | Ввод слова |
| Пробел | Разделитель слов в предложении босса |
| Backspace | Удалить последнюю введённую букву |
| Tab | Сменить цель |
| Esc | Пауза / продолжить |
| Клик по врагу | Выбрать цель вручную |
| Клик по пустому месту | Снять ручной выбор |
| 1–6 | Выбрать карту улучшения |
| «На весь экран» | Развернуть игру на весь экран |
| R | Обновить предложенные улучшения |
| S | Пропустить выбор и получить 15 HP |

## Правила

- Над каждым врагом висит слово. Полностью введённое слово уничтожает врага.
- Все слова всегда вводятся целиком: никакие улучшения не заполняют буквы за игрока.
- Игра сама выбирает подходящую цель по первым буквам. Если слова начинаются одинаково, помогает `Tab` или клик.
- В мягком режиме неверная буква не вводится и не ранит базу. В строгом режиме опечатку нужно стирать `Backspace`.
- База восстанавливает 10% максимального HP после каждой волны.
- Серия растёт за убийства без ошибок и даёт множитель очков.
- После каждой волны до 10-й — выбор карты. Дальше — после чётных волн и после боссов. Редкость влияет на силу и сложность эффекта.
- Всего 30 волн. Боссы — на 5, 10, 15, 20, 25 и 30-й волнах.
- 30 волн делятся на 6 редакций: Черновик, Правка, Корректура, Цензура, Архив и Последняя редакция.
- Фраза босса вводится целиком как одно предложение, слова разделяются пробелом. Пока босс жив, его предложение остаётся в приоритете даже под атакой.
- На части волн действуют пометки редактора: спешка, облава, заглавная буква, красная пометка и сухая страница.
- 35 улучшений, 4 редкости и проклятые карты.
- Рекорд сохраняется в `localStorage`.

## Сложности

- **Легко** — 130 HP, медленнее враги, ошибки прощаются.
- **Стандарт** — 100 HP, обычная игра.
- **Сложно** — 80 HP, быстрее и больнее враги, строгий ввод, больше очков.

## Технические детали

- Чистый HTML/CSS/JavaScript, без сборщика и внешних библиотек.
- Canvas 480×270 с nearest-neighbor масштабированием для пиксельного вида.
- Процедурный звук на Web Audio API, без аудиофайлов.
- Локальный моноширинный шрифт `Roboto Mono` — выбран ради читаемости слов и интерфейса.
- Сохранение настроек, рекорда и просмотра обучения — в `localStorage`.
- Для тестирования доступен отладочный API по адресу `?debug=1` (`window.__SL`).

## Файлы

- `index.html` — разметка экранов и HUD.
- `style.css` — пиксельный интерфейс и адаптивность.
- `data.js` — словарь, враги, волны, боссы, карты и редкости.
- `game.js` — игровой цикл, ввод, волны, улучшения, отрисовка и звук.
- `GDD_Словобой.md` — исходный дизайн-документ.
- `favicon.svg` — иконка.
- `robotomono-*.ttf` — шрифты.
